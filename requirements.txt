#  HOW TO INSTALL
#  -------------------------------------------------------
#  Open the terminal in PyCharm or Visual Studio Code
#  and run the following command:
#
#      pip install -r requirements.txt
#
# ============================================================


# -------------------------------------------------------
#  PyCharm — Terminal Setup
# -------------------------------------------------------
#  1. Open PyCharm
#  2. Click "Terminal" at the bottom of the window
#     (or go to View > Tool Windows > Terminal)
#  3. Make sure the terminal shows your project folder
#  4. Run:  pip install -r requirements.txt
#  5. Once done, run:  python app.py


# -------------------------------------------------------
#  Visual Studio Code — Terminal Setup
# -------------------------------------------------------
#  1. Open VS Code
#  2. Go to Terminal > New Terminal from the top menu
#  3. Make sure the terminal shows your project folder
#  4. Run:  pip install -r requirements.txt
#  5. Once done, run:  python app.py

#  Verify Installation (Optional)
# -------------------------------------------------------
